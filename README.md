# Melbourne Lending System

Static, GitHub-Pages-ready lending web app designed from the supplied SheetLab screenshots.

## Included views
Dashboard, Borrowers, Active Loans, Overdue Monitoring, Capital, Expenses, Settings, Loan Calculator, Loan Agreement, Collectors / Agents, Reports, and Virtual Tour.

## Loan model
- Default loan amount: PHP 10,000
- Default term: 6 months
- Default payments: 12
- Two custom salary dates; Salary Date 1 is always the first due date
- Default grace period: 3 days
- Monthly interest: 5%
- Late penalty: 5%
- No collateral; borrower video statement included in printable agreement

## Run locally
Double-click `index.html` or serve the folder with any static web server.

## GitHub Pages
Upload the contents of this folder to the root of a public repository and enable GitHub Pages from `main` / root.
